# Salice Inteligente v1.2.3

## Alcance comercial de vendedores

- Las siete carteras vigentes son Andres Dominguez, Edgardo Larrea, Ignacio Carea, Ana Ottaviano, Julieta Errecart, Gonzalo Russian y Reventas.
- El programa excluye por nombre a los vendedores históricos y administrativos conocidos hasta la v1.2.2.
- La regla no es una lista blanca: un vendedor nuevo que GESI incorpore queda incluido automáticamente.
- El mismo alcance se aplica al snapshot operativo, productos derivados, logística, Explorador de ventas y reportes construidos sobre movimientos.
- La política documental de Cuentas por cobrar no cambia: conserva sus seis vendedores autorizados y el mínimo pendiente de $1.000.

## Visibilidad global de clientes

El selector global de clientes ofrece cuatro alcances:

1. Compraron en los últimos 3 meses o tienen deuda accionable (predeterminado).
2. Compraron en los últimos 6 meses o tienen deuda accionable.
3. Todos los clientes activos.
4. Todos los clientes.

La selección se guarda por usuario en el navegador y se aplica a búsqueda, mapa, clientes, vendedores, productos, rutas, cartera, bandeja y vistas operativas que reciben clientes. Los filtros propios de cada pantalla se aplican después del alcance global.

## Explorador de ventas

- Seleccionar una barra mensual o un rango profundiza el período sin abandonar el paso 1.
- El usuario puede continuar eligiendo períodos o pasar manualmente a Cliente o Producto.
- Al seleccionar un día exacto, el explorador avanza automáticamente al paso de clientes.

## Persistencia y despliegue

Esta versión no modifica ni elimina la base operativa de usuarios, sesiones, notas, gestiones, vistas guardadas o feedback. La actualización del código y la futura regeneración de datos conservan esos archivos mediante el almacenamiento operativo y el paquete de datos vigente.
