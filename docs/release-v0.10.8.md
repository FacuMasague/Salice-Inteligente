# Salice Inteligente · v0.10.8

## Reportes e IA

- Ventas - Comercial adopta la cabecera, los filtros expandibles, las vistas guardadas y la jerarquía visual común de los reportes por negocio.
- El selector Mensual / Anual usa el control segmentado actual y queda integrado dentro de la presentación del reporte.
- Las narrativas deben citar al menos una evidencia en cada afirmación estructurada y respuesta.
- Una salida que no supera el control de calidad se reintenta antes de quedar bloqueada.
- Las narrativas de los ocho reportes se regeneran con el contrato de evidencia actualizado.

Los reportes determinísticos siguen disponibles aunque una narrativa no pueda publicarse.
