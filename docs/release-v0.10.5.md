# Salice Inteligente · v0.10.5

## Configuración y administración

Configuración se divide en seis secciones:

1. Preferencias.
2. Inteligencia artificial.
3. Datos y actualizaciones.
4. Ayuda.
5. Diagnóstico avanzado.
6. Acerca del programa.

Además:

- La información técnica, catálogos y fórmulas quedan fuera del recorrido cotidiano.
- Se muestra la última actualización publicada.
- La oficina puede registrar horarios previstos y ver cuál es el próximo; estos horarios no automatizan el proceso.
- Presupuesto, consumo y calidad de IA tienen un resumen entendible y un detalle auditable.
- Acerca del programa muestra la versión vigente y el estado de las copias recuperables.
- La restauración permanece como una tarea manual administrada.
