# Salice Inteligente · v0.10.1

## Navegación y experiencia

- El menú conserva cuatro grupos claros: Centro operativo, Administración, Reportes y Sistema.
- Cada pantalla incorpora una ayuda contextual breve con propósito, límites y próximos pasos.
- Configuración permite elegir una densidad cómoda o compacta y ocultar la ayuda contextual.
- Las guías interactivas de Operaciones, Administración y Reportes se mantienen independientes y repetibles.
- Los estados de inicio, carga y error usan mensajes orientados a recuperación y preservación de datos.
- El encabezado de marca usa el isotipo original sin el texto “Salice Distribuciones”, acompañado por “Salice Inteligente”.

No se modificaron cálculos, universos ni datos comerciales.
