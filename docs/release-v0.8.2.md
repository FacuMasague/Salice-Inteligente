# v0.8.2 — Del reporte a la acción

## Alcance

Los reportes mantienen su función analítica, pero ya no terminan el recorrido del usuario al encontrar un número.

- Ventas Comercial abre el Explorador de ventas con período y dimensiones compatibles conservadas.
- Cada producto desplegado en Ventas Comercial puede abrir sus ventas exactas.
- Saldos Pendientes abre Cuentas por cobrar con vendedor o cliente preseleccionado.
- Cuentas no compradoras abre cliente, vendedor, marca o ventas relacionadas.
- Los reportes de marcas conservan enlaces a fichas de marca y, cuando el contrato ofrece productos, a fichas de producto.
- Los ocho reportes ofrecen accesos contextuales hacia reportes compatibles.
- Un enlace copiado abre directamente el reporte y restaura sus filtros conocidos.

## Límites

Reportes no crea gestiones, no modifica cobranzas, no duplica el Explorador de ventas y no registra actividad humana. Cada acción continúa en el módulo operativo dueño de ese proceso.

No se modificaron fórmulas, universos, datos de GESI ni el tutorial.
