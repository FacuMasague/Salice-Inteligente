# v0.9.3 — “¿Cómo estamos?”

## Resultado

La portada conserva sus seis bloques determinísticos y agrega una lectura ejecutiva almacenada.

El paquete de evidencia reutiliza los contratos de:

- Ventas Comercial;
- objetivos mensuales;
- cuentas no compradoras;
- saldos pendientes;
- variaciones por vendedor;
- estados documentales de facturas y fojas.

Cada bloque mantiene definición, período, universo, advertencia y destino de navegación.

## Reglas

La salida separa asuntos principales, indicadores favorables, aspectos para revisar, limitaciones y preguntas frecuentes.

La validación rechaza:

- puntajes únicos;
- semáforos generales;
- referencias de evidencia inexistentes.

El prompt prohíbe sumar universos incompatibles, mezclar objetivos con resultados, afirmar entregas o crear tareas. Una foja cerrada continúa siendo exclusivamente un estado documental.

## Cierre verificado

La ejecución real produjo un resumen ejecutivo válido para el snapshot activo. La repetición reutilizó el artefacto con costo cero.
